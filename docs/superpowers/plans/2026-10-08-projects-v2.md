# Projects v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make projects workspace-level (no boardId), give them a kanban view and documents, and ship the v1 feedback batch (edit dialog, lead pickers, task→project navigation, badge wrap).

**Architecture:** Migration drops `Project.boardId` (workspace projects), frees `Document.taskId/boardId` to nullable + adds `projectId` (XOR-attached, project-scoped doc counter on Project). REST/MCP drop board-scoped project routes for global ones; permissions become all-members; socket project events broadcast globally. Web moves to `/projects` + `/projects/:id`, adds an edit dialog, project kanban (per-status columns, cross-board moves re-board the task), and a documents tab.

**Tech Stack:** NestJS 11 + Prisma 6 + SQLite + Socket.IO; React 19 + Vite + React Query + Tailwind 4.

**Spec:** `docs/superpowers/specs/2026-10-08-projects-v2-design.md` (binding; records the human's four model decisions).

## Global Constraints

- TaskForge task IDs: this plan's work is tracked as NEW TaskForge tasks under a "Projects v2" parent on board TFG — create them in the setup task, one per implementation task.
- No Prisma enums; `PROJECT_STATUSES` const + `@IsIn`/zod enum stay.
- API CommonJS `strict:false`; web ESM `strict:true`; tsc (web) pre-existing error count (5 at plan time) must not grow.
- Prettier (100, single quotes); kebab-case filenames; `pnpm format` on touched files before every commit.
- Activity diffs and all nullable-field writes use `!== undefined` (null-safe), never truthy checks.
- Integration tests: temp SQLite via `createTestPrisma()`; cleanup in afterEach REVERSE dependency order (adjust for Document→Project new FK: project.deleteMany after task.deleteMany but documents referencing projects must go first: order documents(project+task docs) after comments/tasks? — final order: notification, taskSubscription, taskLabel, label, comment, taskRelation, attachment, document, task, project, view, member, status, board, user, session, settings).
- Web test mocks: every hook a component imports from a `vi.mock`ed module must appear in that module's mock factory.
- design.md tokens: dark-only, no gradients, ONE lime CTA per screen, neutral progress bars, Inter ≤590, JetBrains Mono for IDs/numbers/timestamps.
- Migration safety: SQLite column drops/changes rebuild tables; verify data survivability with a dedicated migration test (existing project rows keep name/status/position; docs keep boardId+taskId).
- The publish feature's rule applies to project management endpoints: reject bot sessions (`session.bot`) — projects are human planning surfaces.

## Review Focus

1. **Doc XOR attachment** — creating a document with both taskId and projectId (400), with neither (400), and updating to flip/overlap must be rejected; every create/edit path (REST + MCP + web) pinned.
2. **No cross-board moves** (revised ruling) — a statusId from another board is rejected (400) on REST + MCP move/update; a task's boardId never disagrees with its status.boardId. Project kanban only offers drops into the card's own board's columns. Pinned per Task 5 + Task 8.
3. **Global socket events without rooms** — after v2, project events carry no boardId; every client (any page) must receive them. The emit signature `emit(event, data, boardId?)` with no room must reach ALL connected sockets (existing global broadcast behavior) — pinned by socket tests asserting delivery without a prior room join (Task 4).
4. **Migration data survival** — project rows survive boardId drop; documents survive taskId/boardId re-typing; counters (board.nextDocNum, project.nextDocNum) stay consistent. Pinned per Task 2's migration test.
5. **Stale-link hygiene on task.project.updated** — the extended emit (any project-linked task's move) must still carry previousProjectId and must not fire for tasks with no project and no change; invalidation keys updated to global. Pinned per Task 4.
